
<h1>Inventory Dashboard</h1>

<h2>A simple inventory dashboard made using HTML, CSS, and JavaScript.</h2>

<h3>Features</h3>
<ul>
  <li>Add product</li>
  <li>Edit product</li>
  <li>Delete product</li>
  <li>View total products, value, and stock status</li>
</ul>

<h2>Tech Stack</h2>
<p>HTML, CSS, JavaScript, LocalStorage</p>
